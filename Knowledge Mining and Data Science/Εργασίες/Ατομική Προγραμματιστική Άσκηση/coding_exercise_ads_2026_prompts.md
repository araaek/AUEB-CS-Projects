## Δημιουργία του αρχείου birds_greece_all.csv
| | |
|---|---|
| **Εργαλείο** | Claude (claude.ai) |
| **Μοντέλο** | Claude Sonnet 4.6 |

**Prompt:**

> Έχω κατεβάσει από το GBIF.org ένα αρχείο zip που δημιούργησα με download request με φίλτρα: Country or area Greece, Has coordinate true, Has geospatial issue false, Scientific name Aves, Year Between start of 2001 and end of 2025 και σε μορφή Darwin Core Archive (dwca)
> 
>Αποσυμπιέζοντας το αρχείο που κατέβασα υπάρχουν τα αρχεία occurrence.txt που περιέχει τις εγγραφές που θέλω αλλά δεν περιέχει τις εικόνες. Επίσης στο αρχείο multimedia.txt περιέχονται για οσες εγγραφές διαθέτουν εικόνες, το link για την εικόνα.

>Αυτά τα δύο αρχεία σχετίζονται μεταξύ τους με τα πεδία occurrenceID και gbifID αντίστοιχα.
>Αν μια εγγραφή του occurrence.txt έχει εικόνα τότε η αντίστοιχη εγγραφή στο multimedia.txt έχει στο πεδίο type την τιμή StillImage ΚΑΙ το πεδίο references ΔΕΝ περιέχει το string sounds.

>Θέλω ένα αρχείο csv που να περιέχει τις εγγραφές του occurrence.txt με μία επιπλέον στήλη όπου θα υπάρχει το link για όσες εγγρφές διαθέτουν εικόνες. Το όνομα του αρχείου να είναι birds_greece_all.csv
>Πρότεινέ μου κώδικα σε python
